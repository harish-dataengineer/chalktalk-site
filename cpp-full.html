Unit 2 — Classes, Objects, Constructors & Destructors

Access Specifiers & Constructors

Think of a class like a house with three types of rooms: private rooms only family can enter, public rooms anyone can walk into, and protected rooms only family and close relatives (inherited classes) can access.

A constructor runs automatically the moment the house is built — setting up furniture (initial values) before anyone moves in. A destructor runs automatically when the house is demolished — cleaning up before it's gone.

Now in exam language:
class Student { private: int marks; public: Student(int m) { // Constructor marks = m; } ~Student() { // Destructor cout << "Student object destroyed"; } };

Copy Constructor

High — asked as a direct short question
Now in exam language:

A copy constructor creates a new object as a copy of an existing object of the same class — invoked when you pass an object by value, return one by value, or explicitly copy one (Student s2 = s1;).

Unit 3 — Operator Overloading & Inheritance

Operator Overloading

Normally, + only adds numbers. Operator overloading teaches the + symbol a new trick — like adding two "Complex Number" objects together, or combining two "Distance" objects — using the same familiar symbol for a new kind of data.

Now in exam language:
class Complex { public: int real, imag; Complex operator+(Complex const &obj) { Complex res; res.real = real + obj.real; res.imag = imag + obj.imag; return res; } };

Inheritance & Virtual Functions

Very high — types of inheritance is a guaranteed question
Now in exam language — types of inheritance:
  • Single: one base, one derived class.
  • Multiple: one derived class, multiple base classes.
  • Multilevel: a chain — A → B → C.
  • Hierarchical: one base, multiple derived classes.
  • Hybrid: a combination of the above.

A virtual function is a base class function declared with the virtual keyword, allowing a derived class to override it — and letting a base class pointer call the derived version at runtime. This is how C++ achieves runtime polymorphism.

Unit 4 — Templates

Function & Class Templates

Imagine writing one recipe that works for "swap two apples" but you also need "swap two numbers" and "swap two strings" — instead of writing three near-identical recipes, a template lets you write it once with a placeholder ingredient that gets filled in with whatever type you actually use.

Now in exam language:
template <typename T> T maxValue(T a, T b) { return (a > b) ? a : b; } // Works for int, float, char — any comparable type cout << maxValue(5, 10); // 10 cout << maxValue(2.5, 1.5); // 2.5

This is a Function Template — the compiler generates a specific version of the function for whatever type T ends up being when you call it.

Unit 5 — Exception Handling, Files & STL

Exception Handling in C++

Now in exam language:
try { int x = 10, y = 0; if (y == 0) throw "Division by zero!"; cout << x / y; } catch (const char* msg) { cout << msg; }

C++ uses try, throw, and catch — code that might fail goes in try, the failure is signaled with throw, and it's handled in a matching catch block.

STL — the Standard Template Library

Very high — vectors and STL containers asked frequently

The STL is like a toolbox of pre-built, tested containers — instead of writing your own resizable array or linked list from scratch every time, you just grab a vector or a list that already works.

Now in exam language — common STL containers:
  • vector: a dynamic, resizable array with fast random access.
  • list: a doubly linked list, fast inserts/deletes anywhere.
  • map: key-value pairs, automatically sorted by key.
  • deque: a double-ended queue, fast insertion/removal from both ends.
vector<int> nums = {5, 2, 8}; nums.push_back(10); // {5, 2, 8, 10} map<string, int> marks; marks["Ravi"] = 87; marks["Priya"] = 92;
Explain the STL containers in C++ with suitable examples.10 marks

Tip: cover vector, list, and map at minimum — these three are the most commonly asked in practicals and theory both.
